# Security policy

## Supported code

The current `main` branch is the only branch considered for security fixes while the Grav plugin remains pre-1.0.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Send a private report to `contact@lepotager.org` with the subject `Security — PTM Grav`. Include the affected version or commit, reproduction steps, impact and any suggested mitigation.

Do not include production configuration, personal data, site exports or credentials. Use synthetic examples whenever possible.
